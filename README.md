# 📖 Tentang Project

**Ular Tangga Statistik** merupakan website edukasi berbasis Laravel yang dikembangkan sebagai media pembelajaran interaktif untuk memperkenalkan dan meningkatkan pemahaman pengguna terhadap statistik Indonesia melalui pendekatan gamifikasi.

Aplikasi ini mengadaptasi konsep permainan tradisional **Ular Tangga** ke dalam bentuk digital dengan menambahkan unsur edukasi berupa soal-soal statistik yang harus dijawab oleh pemain selama permainan berlangsung.

Melalui pendekatan ini, pengguna tidak hanya bermain untuk mencapai garis akhir, tetapi juga memperoleh pengetahuan baru mengenai berbagai konsep statistik, data kependudukan, sosial, ekonomi, pendidikan, kesehatan, pertanian, dan informasi statistik lainnya yang relevan.

Aplikasi dirancang untuk memberikan pengalaman belajar yang lebih menarik dibandingkan metode pembelajaran konvensional dengan memanfaatkan unsur permainan, kompetisi, tantangan, pencapaian, dan penghargaan.

# 🎯 Apa itu Ular Tangga Statistik?

Ular Tangga Statistik adalah aplikasi permainan edukasi berbasis web yang menggabungkan mekanisme permainan ular tangga dengan pembelajaran statistik Indonesia.

Dalam permainan ini, pemain akan menggerakkan token berdasarkan hasil lemparan dadu dan berinteraksi dengan berbagai jenis petak yang tersedia pada papan permainan.

Ketika pemain berhenti pada petak tertentu, sistem dapat menampilkan pertanyaan statistik yang harus dijawab oleh pemain. Jawaban yang diberikan akan memengaruhi jalannya permainan sesuai dengan aturan yang telah ditentukan.

Selain sebagai media hiburan, aplikasi ini juga berfungsi sebagai sarana pembelajaran yang membantu pengguna memahami statistik Indonesia secara lebih mudah, menarik, dan menyenangkan.

Aplikasi mendukung permainan secara kompetitif melalui mode Multiplayer serta mode Robot AI yang memungkinkan pengguna bermain melawan komputer tanpa memerlukan pemain lain.

# 🎮 Cara Bermain

Permainan **Ular Tangga Statistik** mengadaptasi permainan ular tangga klasik ke dalam bentuk digital dengan menambahkan unsur edukasi berupa pertanyaan statistik Indonesia.

Setiap pemain akan bermain pada sebuah papan permainan yang terdiri dari beberapa petak. Tujuan utama permainan adalah mencapai petak terakhir lebih dahulu dibandingkan pemain lainnya.

Selama permainan berlangsung, pemain akan berpindah petak berdasarkan hasil lemparan dadu. Pada petak tertentu pemain akan menemukan soal statistik yang harus dijawab sebelum permainan dapat dilanjutkan.

Selain itu, terdapat petak ular dan tangga yang dapat mengubah posisi pemain. Tangga akan membantu pemain naik ke petak yang lebih tinggi, sedangkan ular akan membuat pemain turun ke petak yang lebih rendah.

Permainan berakhir ketika salah satu pemain berhasil mencapai petak terakhir sesuai aturan permainan yang berlaku.

---

## Alur Permainan

Secara umum permainan berlangsung melalui tahapan berikut.

1. Pemain melakukan login ke dalam sistem.
2. Pemain memilih mode permainan.
3. Sistem membuat atau menampilkan ruang permainan.
4. Pemain bergabung ke dalam room.
5. Setelah seluruh pemain siap, permainan dimulai.
6. Sistem menentukan giliran bermain setiap pemain.
7. Pemain melempar dadu.
8. Token pemain berpindah sesuai angka dadu.
9. Sistem mengecek jenis petak yang ditempati pemain.
10. Jika petak berisi soal maka pertanyaan statistik akan ditampilkan.
11. Pemain menjawab soal.
12. Sistem memproses jawaban.
13. Jika pemain berada pada petak tangga maka posisi pemain akan naik.
14. Jika pemain berada pada petak ular maka posisi pemain akan turun.
15. Permainan dilanjutkan hingga terdapat pemain yang mencapai petak terakhir.

# 🎲 Mode Permainan

Aplikasi menyediakan dua mode permainan utama yaitu **Multiplayer** dan **Robot AI**.

---

## 👥 Multiplayer

Mode Multiplayer memungkinkan beberapa pemain bermain bersama dalam satu papan permainan secara bersamaan.

Setiap pemain memperoleh giliran bermain secara bergantian sesuai urutan yang telah ditentukan oleh sistem.

Seluruh aktivitas permainan seperti perpindahan token, lemparan dadu, perubahan giliran, hingga penentuan pemenang dilakukan secara sinkron sehingga seluruh pemain melihat kondisi permainan yang sama.

Mode ini dirancang untuk meningkatkan interaksi antar pemain sekaligus menciptakan suasana belajar yang lebih kompetitif.

### Alur Multiplayer

1. Pemain memilih mode Multiplayer.
2. Pemain membuat room atau bergabung ke room yang tersedia.
3. Sistem menunggu seluruh pemain bergabung.
4. Setelah seluruh pemain siap permainan dimulai.
5. Sistem menentukan giliran pertama.
6. Pemain melakukan lemparan dadu.
7. Token berpindah sesuai angka dadu.
8. Jika berhenti pada petak soal maka soal statistik akan muncul.
9. Jika berhenti pada petak tangga maka pemain naik ke petak tujuan.
10. Jika berhenti pada petak ular maka pemain turun ke petak tujuan.
11. Giliran berpindah ke pemain berikutnya.
12. Permainan selesai ketika salah satu pemain mencapai petak terakhir.

### Fitur Multiplayer

- Room permainan.
- Bermain bersama beberapa pemain.
- Giliran otomatis.
- Sinkronisasi posisi pemain.
- Kompetisi secara real-time.
- Penentuan pemenang otomatis.
- Leaderboard permainan.

---

## 🤖 Robot AI

Mode Robot AI memungkinkan pengguna bermain melawan komputer.

Robot AI bertindak sebagai pemain yang akan melakukan seluruh aktivitas permainan secara otomatis sesuai aturan permainan.

Robot akan memperoleh giliran bermain, melempar dadu, berpindah petak, naik tangga, turun ular, dan mengikuti mekanisme permainan sebagaimana pemain biasa.

Mode ini memungkinkan pengguna tetap dapat bermain meskipun tidak ada pemain lain yang sedang online.

### Alur Robot AI

1. Pemain memilih mode Robot AI.
2. Sistem membuat pemain robot secara otomatis.
3. Permainan dimulai.
4. Pemain dan robot memperoleh giliran secara bergantian.
5. Robot melempar dadu secara otomatis.
6. Robot berpindah sesuai angka dadu.
7. Sistem memproses seluruh aturan permainan.
8. Giliran berpindah secara otomatis.
9. Permainan selesai ketika salah satu pemain mencapai petak terakhir.

### Fitur Robot AI

- Bermain melawan komputer.
- Robot bergerak otomatis.
- Mengikuti seluruh aturan permainan.
- Tidak membutuhkan pemain lain.
- Cocok untuk latihan dan pembelajaran.

# 🚀 Instalasi Lengkap

Ikuti langkah-langkah berikut untuk menjalankan project pada komputer lokal.

## 1. Clone Repository

```bash
git clone https://github.com/cahyantii/ular-tangga-statistik.git
```

---

## 2. Masuk ke Folder Project

```bash
cd ular-tangga-statistik
```

---

## 3. Install Dependency Laravel

```bash
composer install
```

---

## 4. Salin File Environment

Windows

```bash
copy .env.example .env
```

Linux / macOS

```bash
cp .env.example .env
```

---

## 5. Generate Application Key

```bash
php artisan key:generate
```

---

## 6. Konfigurasi Database

Buka file

```env
.env
```

Lalu sesuaikan konfigurasi database.

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=ular_tangga_statistik
DB_USERNAME=root
DB_PASSWORD=
```

---

## 7. Jalankan Migrasi Database

```bash
php artisan migrate
```

Apabila project menggunakan seeder, jalankan:

```bash
php artisan db:seed
```

atau

```bash
php artisan migrate --seed
```
